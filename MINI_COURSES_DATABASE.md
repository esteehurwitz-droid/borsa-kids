2. **Standard (📖 15 min)** - With examples  
3. **Deep Dive (🔬 30+ min)** - Full details + case studies

## Course Metadata

Each course has:
- `id`: unique identifier
- `title`: course name
- `category`: category ID
- `length`: 'quick' | 'standard' | 'deep'
- `duration`: minutes
- `topics`: array of topics covered
- `examples`: real stocks used
- `difficulty`: 1-5 (1=easiest)
- `prerequisites`: array of course IDs
- `relatedCourses`: array of course IDs
